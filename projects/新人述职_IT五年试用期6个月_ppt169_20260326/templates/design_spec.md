# 转正述职绿色模板 - Design Specification

> 适用于转正答辩、述职汇报、阶段复盘、个人总结、岗位认知与工作规划等正式内部汇报场景。

| --- | --- |
| **模板名称** | lute_green_probation |
| **适用场景** | 转正答辩、述职汇报、试用期总结、内部工作复盘 |

| **章节页策略** | **不使用章节页**，由目录页与内容页直接承接 |

## III. 配色系统

### 主色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| **品牌主绿** | `#88C100` | Logo、编号块、标题强调、关键装饰 |
| **浅亮绿** | `#92D050` | 顶部装饰块、横线、标题底块 |
| **深绿边框** | `#85BB05` | 小矩形边框、结构边界 |
| **背景白** | `#FFFFFF` | 页面主背景 |

### 辅助色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| **正文深灰** | `#333F50` | 大标题、正文、结束页核心文字 |
| **中性灰** | `#7F7F7F` | 顶部辅助短线、弱化说明 |
| **浅灰蒙层** | `#D0CECE` | 结束页图片上的信息承载蒙层 |
| **边框灰** | `#AFABAB` | 蒙层描边、弱分隔 |

### 色彩原则

1. 页面以白底为主，绿色只承担结构和强调角色。
2. 不使用高饱和多彩搭配，避免转正场景显得轻浮。
3. 图片页上的文字必须保持深灰或白色高对比。
4. 内容页优先使用单一绿色系统，不额外引入第二主色。

## IV. 字体系统

### 字体建议

**Font Stack**: `Microsoft YaHei, "Segoe UI", Arial, sans-serif`

### 字号层级

| 层级 | 用途 | 建议字号 | 字重 |
| --- | --- | --- | --- |
| H1 | 封面主标题 | 96-120px | Bold |
| H2 | 内容页标题 / 目录标题 | 36-40px | Bold |
| H3 | 目录项 / 分组标题 | 28-38px | Regular / Bold |
| H4 | 内容小标题 | 20-28px | Bold |
| P | 正文内容 | 24-32px | Regular |
| Meta | 页脚信息 / 编号 / 日期 | 16-19px | Regular / Bold |
| Ending | 结束页主文案 | 100-128px | Bold |

### 排版原则

1. 标题允许明显大字号，形成仪式感。
2. 正文区保持宽松行距，避免试用期汇报信息过密。
3. 中文场景优先使用微软雅黑体系，保证 WPS 与 PPT 兼容性。
4. 同页最多保留 3 级文字层次，防止信息层级混乱。

## V. 核心设计原则

1. **成长表达**：强调个人成长、岗位胜任和后续规划，而不是纯咨询汇报语气。
2. **结构清楚**：目录、页标题、内容承载区必须一眼可识别。
3. **绿色识别**：统一使用绿色顶栏和编号体系，形成项目内模板一致性。
4. **图文并存**：封面与结束页保留当前项目原始图片作为底图氛围层，内容页应以可编辑文本和图表为主。
5. **留白充足**：内容覆盖建议控制在 60%-70%，避免述职页面拥挤。
6. **可替换性优先**：目录项、页标题、正文区、姓名与日期应支持占位替换。
7. **项目内适配**：该模板以当前项目使用为目标，不强制向全局模板库的咨询风统一。

## VI. 页面结构规范

### 通用结构

| 区域 | 位置 / 高度 | 说明 |
| --- | --- | --- |
| **顶部识别区** | y=28-76 | 右上 Logo + 左上绿色块 + 横线装饰 |
| **标题区** | y=40-100 | 目录页 / 内容页标题所在区域 |
| **主体内容区** | y=120-640 | 目录列表、正文内容、图表、结论 |
| **底部信息区** | y=660-720 | 姓名、日期、表单编号、版本等元信息 |

### 装饰语言

1. 左上使用两个绿色矩形作为视觉锚点。
2. 页面顶部横向绿色细线从左向右延展，形成统一框架。
3. 顶部右侧可保留品牌 Logo，但不应喧宾夺主。
4. 内容页标题前保留中文序号，如“一、”“二、”，强化汇报结构感。
5. 结束页允许使用图片 + 灰色蒙层的组合，以增强收束感。
6. 封面页与结束页在后续统一风格时，只调整文字、占位符和信息层，不替换原始背景图片。

## VII. 页面类型

### 1. 封面页（01_cover.svg）

特征：

1. 白底 + 大面积背景图片。
2. 主标题为“转正答辩”或等价封面标题。
3. 标题位于页面右下区域，字号显著放大。
4. 页面底部右侧展示姓名、日期、表单编号、版本信息。
5. 适合传达正式、可信、带组织归属感的第一页印象。
6. 封面底图默认沿用当前模板原始图片，不建议替换为新图。

推荐占位：

| 占位符 | 说明 |
| --- | --- |
| `{{COVER_TITLE}}` | 封面主标题，默认可为“转正答辩” |
| `{{USERNAME}}` | 姓名 |
| `{{DATE}}` | 日期 |
| `{{FORM_CODE}}` | 表单编号 |
| `{{VERSION}}` | 版本号 |

### 2. 目录页（02_toc.svg）

特征：

1. 白底，顶部结构与内容页一致。
2. 标题使用“目录”。
3. 目录项采用“绿色编号块 + 虚线延展 + 文本标题”的组合。
4. 当前项目目录页为固定目录项，不做动态占位替换。
5. 目录内容默认锁定为 7 个既定汇报模块。

固定目录内容：

1. 个人基本情况
2. 岗位认知
3. 个人绩效
4. 关键问题突破举例
5. 下一步工作规划
6. 个人的不足和提升计划
7. 建议与求助

### 3. 内容页（03_content.svg）

特征：

1. 白底，顶部绿色装饰与目录页统一。
2. 左侧标题区为“中文序号 + 页面标题”。
3. 主体为开放式内容区，支持文本、图表、流程、案例、数据卡片等。
4. 当前模板已包含 `{{PAGE_TITLE}}` 与 `{{CONTENT_AREA}}` 占位结构，可作为标准页核心。
5. 页面应优先保持可编辑，减少整页位图依赖。

推荐占位：

| 占位符 | 说明 |
| --- | --- |
| `{{SECTION_INDEX}}` | 页面序号，如“一、”“二、” |
| `{{PAGE_TITLE}}` | 页面标题 |
| `{{CONTENT_AREA}}` | 主内容区域 |

### 4. 结束页（04_ending.svg）

特征：

1. 白底 + 图片背景。
2. 下半区使用灰色半透明蒙层承载结束文案。
3. 中央大字使用“THANKS”或对应感谢语。
4. 适合收尾、致谢、答疑引导。
5. 结束页背景图默认沿用当前模板原始图片，不建议替换为新图。

推荐占位：

| 占位符 | 说明 |
| --- | --- |
| `{{THANKS_TITLE}}` | 结束页主标题，如“THANKS”或“感谢聆听” |
| `{{THANKS_SUBTITLE}}` | 补充说明，可选 |

### 5. 章节页（不使用）

说明：

1. 本模板明确**不单独设置章节页**。
2. 汇报节奏通过目录页与内容页内的序号体系来表达。
3. 若未来需要增强章节过渡，建议新增轻量内容过渡页，而不是全屏章节页。

## X. SVG 技术约束

### 强制规则

1. viewBox 必须为 `0 0 1280 720`。
2. 背景统一使用 `<rect>` 绘制。
3. 文本换行使用 `<tspan>`，禁止使用 `<foreignObject>`。
4. 透明度使用 `fill-opacity` 或 `stroke-opacity`，禁止 `rgba()`。
5. 禁止使用：`clipPath`、`mask`、`<style>`、`class`、`foreignObject`。
6. 禁止使用：`textPath`、`animate*`、`script`、`marker-end`。
7. 箭头如有需要，使用 `<polygon>` 实现。
8. 渐变必须通过 `<defs>` + `<linearGradient>` 声明。

### 针对当前模板的特别说明

1. 当前封面页与结束页包含大面积 base64 图片与 `clipPath`，适合作为视觉参考，但不利于后续 PPT 原生编辑。
2. 若要升级为高复用标准模板，应逐步减少整页图片依赖。
3. 内容页是最适合优先标准化的页面，应保留文本和图表可编辑性。
4. 目录页应从固定文案改造为可替换目录项列表。

## XI. 占位符规范

模板统一使用 `{{PLACEHOLDER}}` 语法。推荐采用以下占位符集合：

| 占位符 | 说明 |
| --- | --- |
| `{{COVER_TITLE}}` | 封面标题 |
| `{{USERNAME}}` | 姓名 |
| `{{DATE}}` | 日期 |
| `{{FORM_CODE}}` | 表单编号 |
| `{{VERSION}}` | 版本 |
| `{{SECTION_INDEX}}` | 内容页序号 |
| `{{PAGE_TITLE}}` | 内容页标题 |
| `{{CONTENT_AREA}}` | 内容主体区 |
| `{{THANKS_TITLE}}` | 结束页标题 |
| `{{THANKS_SUBTITLE}}` | 结束页补充说明 |

注：本项目目录页为固定内容页，不定义 TOC 相关占位符。

### 命名建议

1. 统一使用全大写下划线命名，避免当前 `{{username}}` 这类大小写不统一写法。
2. 同一模板内不要混用英文小写与全大写占位风格。
3. 能抽象为通用字段的内容，不建议直接写死在 SVG 中。

## XII. 质量检查清单

### 生成前

- [ ] 页面结构已明确为封面 / 目录 / 内容 / 结束
- [ ] 汇报逻辑已拆分为目录项
- [ ] 内容页的核心结论已先行提炼

### 生成后

- [ ] viewBox = `0 0 1280 720`
- [ ] 顶部绿色结构在目录页与内容页保持一致
- [ ] 所有标题与正文对比度足够
- [ ] 内容页正文未超出安全区域
- [ ] 目录项已替换为真实项目结构
- [ ] 姓名、日期、编号等元信息完整
- [ ] 未使用 `<foreignObject>`
- [ ] 未使用 `clipPath` / `mask` / `style` / `class`
- [ ] 文本可编辑区域优先保留为文字而非位图

## XIII. 使用说明

1. 将本规范作为当前项目模板页的设计标准。
2. 封面页保留强视觉氛围，目录页和内容页优先标准化为可替换结构。
3. 本模板不使用章节页，目录后直接进入内容页。
4. 若后续要做模板清洗，建议优先处理 `03_content.svg`，其次是 `02_toc.svg`。
5. 若要升级为模板库级别标准模板，下一步应统一占位符命名，并减少封面、结束页的整页图片依赖。
